# PRD — База знаний для Telegram бота

## 1. Описание проекта

**Название проекта:** База знаний для Telegram бота

**Тип проекта:** Web-приложение (SPA)

**Суть проекта:** Web-интерфейс для управления базой знаний — системой пар "категория → ответ", которая используется Telegram ботом для ответов на запросы пользователей.

## 2. Целевая аудитория

- **Администраторы системы:** Пользователи с правами управления базой знаний (добавление, редактирование, удаление)
- **Пользователи бота:** Конечные пользователи Telegram, которые получают ответы на основе базы знаний

## 3. Основные функции

### 3.1 Управление категориями и ответами

| Функция                | Описание                                     |
|------------------------|----------------------------------------------|
| Просмотр списка        | Отображение всех пар "категория → ответ"     |
| Добавление             | Создание новых записей                       |
| Редактирование         | Изменение существующих записей               |
| Удаление               | Удаление записей                             |
| Поиск                  | Фильтрация/поиск по содержимому              |

### 3.2 Структура данных

```
{
  "id": "uuid",
  "category": "название категории (для поиска)",
  "answer": "текст ответа (для вывода в Telegram)"
}
```

### 3.3 Валидация

- Оба поля обязательны
- Поля не должны быть пустыми
- Минимальная длина: 3 символа

### 3.4 UI/UX требования

- Адаптивный дизайн (Desktop и Mobile)
- Современный, чистый интерфейс
- Стек: **React** + **Vite**
- Возможность расширения тем

## 4. Функциональные требования

### 4.1 Доступ к приложению

- Доступ по URL
- Возможность настройки ограничения доступа (текущий вариант — без авторизации)

### 4.2 Управление данными

| Действие  | Требование                                      |
|-----------|-------------------------------------------------|
| Создание  | Форма с валидацией                             |
| Редактир. | Возможность изменить оба поля                  |
| Удаление  | Подтверждение удаления                         |
| Поиск     | Фильтрация по категории/ответу                 |

### 4.3 Отображение данных

- Таблица или список карточек
- Сортировка (по дате, по категории)
- Пагинация или бесконечный скролл (при большом объёме данных)

## 5. Нефункциональные требования

| Характеристика  | Требование                           |
|----------------|--------------------------------------|
